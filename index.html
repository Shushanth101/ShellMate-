Why ShellMate?

Long-Term Memory

ShellMate remembers you. It stores facts about your preferences and projects, injecting them into context for personalized assistance.

Secure Authentication

Built-in user management with hashed passwords ensures your chat history and memory remain private.

Client-Server Architecture

Robust Flask backend handling persistence, decoupled from the lightweight CLI client for maximum flexibility.

Agentic Tools

Powered by LangChain, ShellMate can browse the web, read files, and execute python code to solve complex tasks.

Get Started

Terminal 
# Clone the repository
git clone https://github.com/Shushanth101/ShellMate-.git
cd shellmate

# Install dependencies

# Start ShellMate
python src/main.py --signup
